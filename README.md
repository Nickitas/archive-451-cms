# Архив 451

**Читательский дневник — личная библиотека прочитанных книг с заметками в духе Obsidian**

Next.js 16 · Payload CMS · PostgreSQL · Tailwind CSS 4 · shadcn/ui

</div>

---

## О проекте

Саламандра, живущая в огне, здесь — хранитель архива: книги и
заметки к ним. Название и айдентика — отсылка к роману Р. Брэдбери: **451 °F по Фаренгейту** — температура, при которой воспламеняется бумага.

Пользователь добавляет прочитанные книги (обложка, описание, оценка, теги, статус), а к каждой
книге ведёт заметки в Markdown — анализ, суть, краткое содержание. Ввод данных — через админку
Payload, фронтенд — витрина библиотеки для себя и тех, кому подарена ссылка.

## Возможности

- **Библиотека** — сетка книг с поиском по названию/автору, фильтрами (статусы, теги, мин. рейтинг), сортировкой и пагинацией; режимы «плитка» и «список»
- **Карточка книги** — обложка, мета (статус, оценка, дата прочтения, теги), описание, ссылка на Яндекс.Книги
- **Заметки** — Markdown с GFM (цитаты, таблицы, код), сколько угодно на книгу
- **Темы** — светлая, тёмная и системная с переключателем в хедере
- **Админка Payload** — управление коллекциями books / notes / media

## Быстрый старт

Требования: **Node 20+** (разрабатывается на 22), **pnpm 10**, **Docker**.

```bash
# 1. Зависимости
pnpm install

# 2. Переменные окружения
cp .env.example .env   # заполнить DATABASE_URI и PAYLOAD_SECRET

# 3. Инфраструктура (Postgres + MinIO)
docker compose up -d

# 4. Запуск dev-сервера
pnpm dev
```

- Витрина: <http://localhost:3000>
- Админка: <http://localhost:3000/admin> — при первом входе Payload предложит создать пользователя

> ⚠️ Postgres поднимается на порту **5433** (5432 на хосте занят системным Postgres — при
> необходимости поправьте маппинг в `docker-compose.yml` и `DATABASE_URI`).

## Структура

```
src/
├── app/
│   ├── (app)/          # витрина: layout, страницы / и /books/[id], тема
│   ├── (payload)/      # админка и API Payload
│   └── icon.svg        # фавикон
├── modules/
│   ├── admin/          # payload.config.ts и коллекции
│   └── books/          # фича «книги»: compose / model / domain / repository / ui
└── shared/
    ├── components/     # каркас (SiteHeader, SiteContainer, темы) + ui-kit shadcn
    └── lib/            # утилиты
```

Слои фичи читаются так: `compose` собирает серверные данные → `model` хранит состояние view →
`domain` — чистые функции и типы → `repository` — единственная точка доступа к Payload →
`ui` — презентационные компоненты.
