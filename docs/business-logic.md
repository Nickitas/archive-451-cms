# Бизнес-логика · archive-451-cms

> Фичи, пользователи, сущности и зависимости функций. Стиль кода — `docs/tech-specs.md`,
> дизайн — `docs/design.md`.

## Идея продукта

Читательский дневник: пользователь читает множество книг и ведёт свою базу знаний, чтобы
вернуться к конкретной книге и освежить в памяти её основные идеи и сюжет без перечитывания.
Заметки ведутся в формате Markdown, в духе Obsidian. Библиотеку можно показать другим —
поделиться ссылкой на просмотр ограниченному кругу читателей.

**Сценарий:** админка (Payload) — ввод данных (книги, заметки). Фронтенд — «витрина» библиотеки:
сетка книг с фильтрами → страница книги со всеми её заметками.

## Пользователи

| Кто | Что делает | Как |
| --- | ---------- | --- |
| Владелец библиотеки | Вводит книги, обложки, заметки | `/admin` (Payload, коллекция `users`, auth) |
| Читатели | Просматривают библиотеку и заметки | `/` и `/books/[id]` — после входа через `/auth` (группа `(private)`); шеринг ссылки — в дорожной карте |

## Страницы и фичи

| Маршрут       | Что показывает                                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `/`           | Библиотека: сетка книг, поиск по названию/автору, фильтры (статус, теги, рейтинг), сортировка, пагинация, вид плитка/список; доступ после входа |
| `/books/[id]` | Книга: обложка, мета (статус, оценка, дата, теги), описание, кнопка «Открыть в Яндекс.Книгах», заметки книги (Markdown); доступ после входа |
| `/auth`       | Вход и регистрация на одном экране (карточка с переключателем); регистрация с авто-входом, сессия — httpOnly cookie; ссылка «Забыли пароль?»; авторизованного редиректит на `/` |
| `/auth/forgot-password` | Восстановление пароля: ввод почты; ответ одинаков для любой почты (анти-энумерация), письмо со ссылкой уходит через email-адаптер (в dev — в консоль сервера); авторизованного редиректит на `/` |
| `/auth/reset-password?token=` | Новый пароль (+ повтор) по одноразовому токену из письма (живёт 1 час); успех → авто-вход на `/`; без токена или с просроченным — «Ссылка недействительна» и ссылка на повторный запрос; авторизованного редиректит на `/` |
| `/profile`    | Профиль: аватар-инициал, почта, роль, «В архиве с …»; вход через меню пользователя в хедере |
| `/notes`, `/settings` | Личный кабинет: все заметки, настройки — пока заглушки; вход через меню пользователя в хедере |
| `/admin`      | Панель Payload: ввод книг и заметок                                                                                      |

## Сущности

### Книга (`books`)

| Поле          | Тип                                   | Примечание       |
| ------------- | ------------------------------------- | ---------------- |
| `title`       | text, required                        |                  |
| `author`      | text                                  |                  |
| `description` | textarea                              | краткое описание |
| `cover`       | upload → media                        | обложка          |
| `sourceUrl`   | text (лейбл «Ссылка на Яндекс.Книги») |                  |
| `status`      | select `want`/`reading`/`done`        | default `want`   |
| `rating`      | number 0–10                           | 0 = не оценена   |
| `finishedAt`  | date (sidebar)                        | дата прочтения   |
| `tags`        | array of `tag`: text                  | теги/жанры       |

### Заметка (`notes`, defaultSort `-createdAt`)

`title` (text, required), `book` (relationship → books, required), `content` (textarea «Заметка (Markdown)»).

### Прочее

`media`: `alt` (text, required) + upload, `read: () => true`. `users`: auth.
Сгенерированные типы: `src/modules/admin/payload-types.ts`. Второго `payload-types.ts` в корне быть не должно.

Доменные типы (маппинг в `repository/books-repository.ts`): `Book = { id, title, author, description,
coverPath, sourceUrl, status, rating, finishedAt, tags, notesCount }`;
`Note = { id, title, bookId, content, createdAt }`.

## Правила и расчёты (зависимости функций)

- **Статусы**: `want` → «Хочу прочитать», `reading` → «Читаю», `done` → «Прочитана»
  (`BOOK_STATUS_LABELS`). `finishedAt` заполняется только для прочитанных.
- **Рейтинг**: шкала 0–10; `0` = «не оценена» — пилюля рейтинга не показывается, фильтром
  «мин. рейтинг» такие книги **не отсеиваются** (`book.rating > 0` в условии).
- **`notesCount`** считается репозиторием одним запросом notes (Map по `bookId`) — в БД не хранится.
- **Маппинг**: `cover.url → coverPath`; отсутствующие значения → `''` / `0` / `null`; `getBook`
  возвращает `null` при отсутствии (catch NotFound) → compose вызывает `notFound()`.
- **Мок-данные**: при инициализации Payload (`onInit` → `src/modules/admin/seed/mock-books.ts`)
  в **пустую** коллекцию books сеются три книги с разными статусами — «451 градус по Фаренгейту»
  (прочитана), «Мастер и Маргарита» (читаю), «Государство» Платона (хочу прочитать).
  Вместе с книгами создаются заметки: три у «451 градуса» (суть, цитаты, анализ — с таблицей GFM),
  одна у «Мастера и Маргариты», у «Государства» заметок нет.
  Обложки берутся из `media/`: документ media переиспользуется по имени файла, иначе создаётся
  из файла на диске. При перезапусках и при непустой коллекции ничего не создаётся.
  Ручной запуск — `pnpm exec payload run scripts/seed.ts`.

### Фильтрация и сортировка (`domain/book-filters.ts`, `filterAndSortBooks`)

- Поиск — подстрока без учёта регистра по `title` и `author`.
- Статусы: пусто = все; выбраны — книга подходит при совпадении хотя бы с одним (ИЛИ).
- Теги: пусто = все; книга подходит, если имеет **хотя бы один** из выбранных тегов.
- Рейтинг: порог «от N» применяется только к оценённым книгам.
- Сортировки: `title-asc` (localeCompare), `rating-desc`, `finished-desc` (дата прочтения,
  отсутствующая = 0), `added-desc` (id). Дефолт — `title-asc`.
- `countActiveBookFilters`: поиск (0/1) + статусы (1, если выбраны не все) + кол-во выбранных тегов + рейтинг (0/1).
- Пагинация: размеры страницы 12/24/48; фильтрация и пагинация — **клиентские**
  (рассчитано на ~200 книг; серверная — в дорожной карте).
- Теги для фильтра собираются из всех книг: уникальные, отсортированные (`collectBookTags`).

### Плюрализация (`domain/note.ts`)

«1 заметка» / «2–4 заметки» / «5+ заметок» (`pluralizeNotes`); даты — `ru-RU`.

## Дорожная карта

1. Редактор заметок на фронтенде (аутентификация готова: вход/регистрация `/auth` + сессия; создание/правка заметок без админки).
2. **Obsidian-фичи:** wiki-links `[[Заметка]]`/`[[Книга]]` с автослинком, backlinks, теги `#tag` в тексте.
3. Экспорт книги в `.md` (папка Obsidian) и импорт из неё.
4. Автозаполнение книги по ссылке/поиску Яндекс.Книг (API) — обложка, автор, описание.
5. Серверная фильтрация/пагинация через Payload queries (за пределами ~200 книг).
6. Глобальный поиск по заметкам; коллекция `authors`; S3-сторадж для media (MinIO); шеринг библиотеки по ссылке.
